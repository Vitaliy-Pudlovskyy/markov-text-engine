# Генератор тексту на основі моделі Маркова

Цей проєкт реалізує генератор тексту за допомогою моделі Маркова на основі n-грам. Програма навчається на текстовому корпусі, створює модель переходів між словами та генерує нові послідовності тексту.

---

## Особливості

- Підтримка n-грам різної довжини (2-5 і більше).
- Три режими генерації тексту: випадковий старт, найпоширеніший старт, ручний вибір стартової n-грамми.
- Режим чату, де модель відповідає на ваші фрази, підтримуючи контекст.
- Безпечний ввід даних з перевіркою.
- Очищення та нормалізація тексту (підтримка української, англійської та інших мов на основі кирилиці і латиниці).
- Пошук схожих стартових n-грам при ручному виборі.

---

## Використання

1. Помістіть корпус тексту у файл `text.txt` в кодуванні UTF-8.
2. Запустіть `main.py`.
3. Оберіть режим роботи:
    - 1 / random — випадковий старт, випадкові параметри.
    - 2 / most_common — генерація з найпоширенішою початковою n-грамою.
    - 3 / manual — ручний вибір початкової n-грамми.
    - 4 / exit — вийти з програми.
    - 5 / chat — режим чату з моделлю.
4. Далі слідуйте підказкам програми.

---

## Файлова структура

- `main.py` — точка входу, керує режимами роботи.
- `markov_chain.py` — клас моделі Маркова з методами навчання та генерації.
- `utility.py` — допоміжні функції для вводу та очищення тексту.
- `chat_mode.py` — реалізація інтерактивного режиму чату.
- `text.txt` - текст для навчання
